MANDARIN MASTER – CÀI ĐẶT BIỂU TƯỢNG TRÊN IPHONE

Trong ZIP có sẵn index.html và các file icon/manifest.

CÁCH CẬP NHẬT GITHUB PAGES
1. Giải nén ZIP.
2. Mở repository GitHub đang chứa website.
3. Upload/ghi đè index.html, apple-touch-icon.png, manifest.json, favicon-32.png và thư mục icons.
4. Commit changes và chờ GitHub Pages cập nhật.
5. Đảm bảo các file nằm cùng cấp với index.html; thư mục icons nằm bên cạnh.

CÁCH THÊM RA MÀN HÌNH CHÍNH IPHONE
1. Mở địa chỉ website bằng Safari (không phải trình duyệt bên trong ứng dụng).
2. Chạm nút Chia sẻ.
3. Chọn Add to Home Screen / Thêm vào MH chính.
4. Tên hiển thị: Mandarin. Chọn Add / Thêm.

LƯU Ý
- Đây là web app cài từ Safari, không phải ứng dụng App Store.
- Đường dẫn tài nguyên dùng dạng tương đối (./), phù hợp cả GitHub Pages dạng username.github.io/repository/.
- Dữ liệu học hiện tại vẫn lưu trong bộ nhớ trình duyệt trên thiết bị.
